# Code of Conduct

BauPilot Community aims to be a professional, constructive and welcoming open-source project.

Participants are expected to communicate respectfully, focus criticism on ideas and code, avoid harassment or discrimination, and protect private or customer information.

Project maintainers may edit, hide or remove contributions that are abusive, intentionally disruptive, disclose private data, or create avoidable security risk.

For security matters, use the process described in [SECURITY.md](SECURITY.md) rather than public discussion.
