# Contributing

Contributions to BauPilot Community are welcome.

## Good first contributions

- bug fixes
- accessibility improvements
- mobile UX improvements
- construction checklist templates
- offline behaviour
- import/export improvements
- tests
- documentation and translations

## Workflow

1. Fork the repository.
2. Create a focused feature branch.
3. Add or update tests where appropriate.
4. Run `npm test`.
5. Open a pull request explaining what changed, why it is useful and how it was tested.

## Public-repository rules

Never commit:

- production credentials, secrets or API keys
- private project or customer data
- personal data
- private endpoints
- proprietary third-party assets without redistribution rights

For vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
